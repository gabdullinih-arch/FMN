# Документация FMN

FMN («Незабудка», Forget-me-not) — настольный планировщик времени с недельной сеткой. Приложение работает локально: интерфейс написан на React, оболочка — на Tauri 2, данные хранятся в SQLite.

## Разделы

- [Руководство пользователя](./user-guide.md) — устройство календаря, панели, шаблоны, повторы, PlanScript, импорт и экспорт.
- [Руководство разработчика](./developer-guide.md) — архитектура, настройка среды, сборка, тесты, миграции и модель хранения.
- [Системный анализ](../SA/README.md) — единый каталог требований, сценариев, модели данных, архитектуры, интеграций и рисков.

## Важно о PlanScript

Спецификация PlanScript находится в [каталоге системного анализа](../SA/planscript-spec.md) и описывает целевой язык; она может включать возможности шире текущей реализации. Для фактически доступного синтаксиса и встроенных функций приоритетны исходники `src/script/` и тесты `tests-frontend/planscript.test.mjs`. В интерфейсе есть редактор с предпросмотром и применением сценариев, терминал только для чтения и сохранённые наблюдатели. Не запускайте незнакомый сценарий без проверки предпросмотра.

## Версия документации

Документация описывает поведение, подтверждённое текущим исходным кодом. Сборка и тестирование официально описаны для Windows x64; поддержка других операционных систем здесь не заявляется.
