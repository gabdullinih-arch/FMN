# Tauri-приложение FMN

Tauri 2 обвязка хранится в `app/`, React frontend — в корне проекта, а
SQLite-слой — в `src-tauri/`. Приложение отображается как «Незабудка» на
русском и “Forget-me-not” на английском; короткое имя — FMN. Идентификатор
пакета `com.planner.app` оставлен без изменения, чтобы обновление продолжило
использовать существующую папку данных пользователя.

## Сборка и проверки

Из корня проекта соберите frontend:

```powershell
npm ci
npm run build
```

Затем из `app/` выполните проверку или сборку:

```powershell
cargo check
cargo tauri dev
cargo tauri build
```

Перед `cargo tauri dev` и `cargo tauri build` Tauri автоматически запускает
сборку frontend из корня проекта.

Release executable создаётся как `app/target/release/fmn.exe`. Bundles
используют `productName` из `app/tauri.conf.json` и создаются в
`app/target/release/bundle/`.

SQLite-файл находится в каталоге `app.path().app_data_dir()` и не переносится
при переименовании приложения. Каталог создаётся до открытия БД.

## Импорт, экспорт и уведомления

Резервная копия JSON содержит поддерживаемые данные приложения; импорт
заменяет текущую базу транзакционно. Экспорт всех рефлексий создаёт Markdown
файл. Оба действия находятся в панели настроек.

Windows-уведомления используют `tauri-plugin-notification`; для их проверки
соберите и установите приложение, разрешите уведомления в настройках ОС и
проверьте тестовое уведомление из панели настроек. Планировщик напоминает о
событиях только пока приложение запущено.
