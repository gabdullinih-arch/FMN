# Интеграции и обмен данными

## Внутренние интерфейсы

| Источник | Получатель | Контракт и ответственность |
|---|---|---|
| React UI (`src/`) | Tauri API | Асинхронные команды через `@tauri-apps/api/core.invoke`; клиентские вызовы собраны в `src/storage.js`. |
| Tauri adapter (`app/src/main.rs`) | `planner-storage` | Команды адаптируют транспортные DTO и передают операции в Rust-хранилище; ошибки должны возвращаться UI, а не превращаться в успех. |
| `planner-storage` | SQLite | Запросы, транзакции и применение последовательных миграций; файл БД расположен в каталоге данных приложения. |
| React UI | Tauri plugins / ОС | Диалоги, выбор файлов, файловые операции и уведомления реализуются плагинами Tauri. |

Поток компонентов и последовательности операций показаны в [архитектуре](./architecture.md). Точные сигнатуры команд определяются `app/src/main.rs`, `src/storage.js` и сериализуемыми типами, а не этой обзорной таблицей.

## Файловые форматы

### JSON-резервная копия

- Используется для экспорта/восстановления локальных данных.
- Восстановление заменяет текущие данные; перед ним рекомендуется сохранить отдельную резервную копию.
- Ожидаемые свойства: проверка структуры/версии payload и отсутствие частичного состояния при отказе.
- Поддерживаемая схема определяется реализацией `src-tauri/src/backup.rs`; не редактируйте JSON вручную без понимания формата.

### iCalendar (ICS)

- Импорт преобразует поддерживаемое подмножество календарных событий в модель интервалов FMN.
- Экспорт представляет события FMN в пределах возможностей формата.
- Сложные внешние повторения не становятся динамическими правилами FMN; события без распознаваемого времени могут быть пропущены.
- Перед обменом проверяйте результат и сообщения о пропущенных записях. Полное сохранение всех свойств произвольного ICS не гарантируется.

### Markdown для рефлексий

Рефлексии можно экспортировать в Markdown за год или за все годы. Это экспорт пользовательского содержимого, а не механизм восстановления базы.

## Транзакции, отмена и ошибки

- Backend-операции массового применения шаблонов/повторов выполняются транзакционно.
- Undo — отдельная функция интерфейса и не является свойством всех операций импорта/экспорта.
- Отмена диалога должна останавливать соответствующее действие до записи.
- Ошибка записи и ошибка последующей перезагрузки интерфейса должны различаться: после commit данные уже могут быть изменены.
- Подробные ограничения по форматам, конфликтам и отмене описаны в [требованиях](./requirements.md).
