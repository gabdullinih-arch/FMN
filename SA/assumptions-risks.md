# Допущения, ограничения и риски

## Подтверждённые ограничения продукта

- Нет учётных записей, удалённой синхронизации, совместной работы и удалённого резервного хранения.
- Применение шаблона и правила повтора создаёт обычные календарные данные; это не постоянная ссылка на будущие события.
- Удаление шаблона не отменяет прежнее применение; удаление правила не удаляет материализованные интервалы.
- Повторы ограничены конечным горизонтом 1–520 недель.
- Уведомления не являются фоновой службой после закрытия приложения.
- ICS обрабатывается в пределах подмножества, совместимого с текущей моделью FMN.
- Проверенной целевой платформой является Windows x64.

## Допущения, требующие подтверждения

| Допущение | Последствие, если неверно |
|---|---|
| Работает один пользователь на одной локальной установке. | Потребуются блокировки, конфликтная синхронизация или серверная модель. |
| Пользователь понимает, что восстановление JSON-копии заменяет текущие данные. | Нужен более строгий диалог подтверждения и автоматическая защита перед заменой. |
| Ограниченного подмножества ICS достаточно для ожидаемого обмена. | Потребуется спецификация импорта/экспорта и расширение тестов совместимости. |
| Локальная база ОС защищена средствами платформы. | Может потребоваться шифрование БД/резервных копий и модель ключей. |
| Планируемый объём данных соответствует текущим запросам SQLite. | Нужны измерения, индексы/оптимизация и целевые объёмы. |

## Риски и меры контроля

| Риск | Возможное влияние | Текущее средство контроля / рекомендуемое действие |
|---|---|---|
| Повреждение/несовместимость локальной БД или миграции | Невозможность запуска либо потеря доступа к данным. | Последовательные миграции; покрыть негативные тесты запуска и документировать восстановление. |
| Ошибка пакетной записи | Частично изменённое расписание. | Транзакции для массового применения; поддерживать тесты отката. |
| Пользователь ожидает, что удаление шаблона/правила отменит прошлые действия | Неожиданное сохранение старых интервалов. | Явно сообщать о независимости материализованных записей; в будущем рассмотреть метаданные происхождения. |
| Восстановление неверного JSON или ошибочный выбор файла | Замена текущих данных. | Предупреждать о замене и рекомендовать отдельный backup; проверить атомарность импорта. |
| Внешний ICS содержит неподдерживаемые свойства/повторы | Потеря части семантики календаря. | Показывать результаты/пропуски и описывать ограниченное подмножество. |
| Спецификация PlanScript опережает фактический runtime | Пользователь/разработчик полагается на отсутствующую функцию. | Помечать статус документа; считать исходники и тесты фактическим контрактом. |
| Ошибка UI после успешного commit | Пользователь может повторить уже выполненную операцию. | Различать сбой записи от сбоя обновления; показывать состояние commit явно. |
| Недостаточное покрытие отказов | Регрессии проявляются только на реальных данных. | Добавить отрицательные сценарии для импорта, восстановления, отмены и отказа команд. |
| Неизмеренные пределы объёма данных | Долгий поиск/открытие календаря на больших историях. | Определить ожидаемые объёмы и SLA, затем измерить. |
